# Kollmorgen AKM44H — brushless servo motor

10-pole surface-PM servo. First multi-voltage torque-speed envelope
anchor: the catalog publishes the same winding's rated point
at four DC bus voltages (160/320/560/640 Vdc), all below the 6000 rpm
mechanical cap.

## Source

Kollmorgen, "AKM Servomotor Selection Guide with AKD Servo Drive
Systems," column AKM44 / winding H.
