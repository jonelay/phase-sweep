# UW/ORNL 6-kW FSCW SPM

36-slot/30-pole fractional-slot concentrated-winding surface-PM
(El-Refaie/Jahns prototype). First measured torque-speed envelope
anchor: the report publishes four field-weakening verification points
(800–4000 rpm) with measured phase voltage, d/q currents, and shaft
torque.

## Source

J. M. Bailey, J. W. McKeever, "Fractional-Slot Surface Mounted PM
Motors with Concentrated Windings for HEV Traction Drives,"
ORNL/TM-2005/183, Oct 2005.
DOI: [10.2172/885979](https://doi.org/10.2172/885979)

Peer-reviewed companions:
El-Refaie & Jahns, IEEE TIA 41(3):790–800, 2005,
DOI [10.1109/TIA.2005.847304](https://doi.org/10.1109/TIA.2005.847304);
El-Refaie et al., IEEE TIA 42(2), 2006,
DOI [10.1109/TIA.2005.863903](https://doi.org/10.1109/TIA.2005.863903).
