# NWPU 12 kW 3-Segment Halbach Array PMSM

20-pole/24-slot inrunner with a 3-segment Halbach magnetization array.
Prototype manufactured and back-EMF tested (measured 75.2 V line peak
at 1000 r/min). First Halbach-magnetization motor in the validation set.

## Source

Liu, J.; Shang, M.; Gong, C. "Analytical Modeling and Analysis of
Halbach Array Permanent Magnet Synchronous Motor," *World Electric
Vehicle Journal*, 16(8):413, 2025.
DOI: [10.3390/wevj16080413](https://doi.org/10.3390/wevj16080413)
