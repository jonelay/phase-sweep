# Zhang 2021 — 9-slot/8-pole segmented Halbach array PMSM

First Halbach motor with full geometry and measured back-EMF closure.
Prototype fabricated and tested — measured back-EMF at 400 r/min agrees
with analytical and FEA within 4.2%.

## Source

Zhang, H.; Yang, M.; Zhang, Y.; Tuo, J.; Luo, S.; Xu, J., "Analytical
field model of segmented Halbach array permanent magnet machines
considering iron nonlinearity," IET Electric Power Applications,
15:717–727, 2021. DOI: [10.1049/elp2.12069](https://doi.org/10.1049/elp2.12069).
Open access (CC-BY-4.0).
