# CREATOR Case PMSM — Reference Data

This directory contains reference data from the **CREATOR** open-benchmark
PMSM (Permanent Magnet Synchronous Motor), a 70 W, 4-pole, 6-slot machine
with sintered ferrite magnets and concentrated single-layer windings.

## Source

**Paper:**
Muetze, A., Heidarikani, K., Dhakal, P. K., Seebacher, R., & Schöps, S.
(2025). "'CREATOR case': PMSM and IM electric machine data for validation
and benchmarking of simulation and modeling approaches." *COMPEL*, 44(4),
392–410.
- arXiv preprint: https://arxiv.org/abs/2501.15921
- Journal DOI: https://doi.org/10.1108/compel-11-2024-0462

**Dataset:**
DOI: [10.3217/sns1d-77m43](https://doi.org/10.3217/sns1d-77m43)

**Institution:**
CREATOR CRC-TRR361 — TU Graz / TU Darmstadt / JKU Linz

## File Manifest

| File | Contents | Origin |
|------|----------|--------|
| `reference_scalars.json` | Design parameters, circuit values, geometry, material properties | Compiled by us from paper Tables 6–12. **Not in public releases** |
| `backemf_measured.json` | Measured back-EMF fundamental (scalar summary) | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` from back-EMF scope capture FFT |
| `mtpa_angles.json` | MTPA current angles | Transcribed by us from paper §6.2.2 (text; 100°el / 110°el at 0.15 / 0.30 A). **Not in public releases** |
| `torque_rated.json` | Rated/max torque reference values | Transcribed by us from paper Table 6. **Not in public releases** |
| `ferrite_bh.csv` | Ferrite B-H curve (7 points, demagnetization quadrant) | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` |
| `iron_losses_measured.csv` | No-load iron loss vs frequency (16 points) | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` |
| `iron_loss_noload.json` | Same curve in import format: `p_fe` at the rated point, full sweep in `waveforms` | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` from `iron_losses_measured.csv` |
| `b_core_calibration.record.json` | Calibration record for the motor TOML's `B_core` | Generated by `scripts/calibrate_creator_b_core.py` (needs the fetched dataset). **Not in public releases** |
| `m250_35a_bh_50hz.csv` | M250-35A steel B-H curve + core loss + permeability (33 points) | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` |
| `no_load_torque_measured.csv` | No-load torque vs speed (16 points) | **Not shipped** — generated by `scripts/fetch_creator_dataset.py` |
| `.gitignore` | Excludes full dataset ZIP and extracted tree | — |

The motor configuration file `motors/creator_case_pmsm.toml` is our own
file with parameter values transcribed from the paper. It is covered by
the project's Apache-2.0 license.

## Fetching Dataset Files

Four CSV files are extracted from the CREATOR dataset (CC BY-NC-ND 4.0)
and are **not** shipped in the repository. To generate them:

```bash
uv run python scripts/fetch_creator_dataset.py
```

This downloads the dataset ZIP from the canonical source and writes
`ferrite_bh.csv`, `iron_losses_measured.csv`, `m250_35a_bh_50hz.csv`,
and `no_load_torque_measured.csv`. Tests that need these files are
skipped automatically when they are not present.

## Full Dataset (for Tier 2 tests)

Some tests in `tests/crossval/test_creator_model.py` additionally require the
full extracted dataset tree (back-EMF and cogging torque waveform CSVs).
After running the fetch script above, unzip in this directory:

```bash
cd data/creator_case_pmsm && unzip PM_synchronous_motor.zip
```

The expected path is `data/creator_case_pmsm/PM_synchronous_motor/`.
Tests that need the full dataset are skipped automatically with a message
when the data is not present.
