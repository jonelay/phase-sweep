# CREATOR Case Induction Motor — Reference Data

This directory contains reference data from the **CREATOR** open-benchmark
squirrel-cage induction motor: 3.7 kW nominal / 4.6 kW max, 400 V rms L-L
wye, 6.9 A rms nominal, 50 Hz, 4-pole, 1430 rpm rated (s = 4.67%),
36 stator slots / 28 rotor cage bars, totally enclosed water cooled. It is
the sibling machine of the CREATOR PMSM already anchored in
`data/creator_case_pmsm/` — same paper, same institution, sibling dataset.

## Source

**Paper:**
Muetze, A., Heidarikani, K., Dhakal, P. K., Seebacher, R., & Schöps, S.
(2025). "'CREATOR case': PMSM and IM electric machine data for validation
and benchmarking of simulation and modeling approaches." *COMPEL*, 44(4),
392–410. (Section 5 documents the induction
machine; Section 6 the PMSM.)
- arXiv preprint: https://arxiv.org/abs/2501.15921
- Journal DOI: https://doi.org/10.1108/compel-11-2024-0462

**Dataset:**
DOI: [10.3217/kh3v7-dhn98](https://doi.org/10.3217/kh3v7-dhn98)

**Institution:**
CREATOR CRC-TRR361 — TU Graz / TU Darmstadt / JKU Linz

## Fetching Dataset Files

```bash
uv run python scripts/fetch_creator_im_dataset.py
```

This downloads the dataset ZIP from the canonical source, extracts the
CSVs listed above, and flattens the raw locked-rotor / no-load `.mat`
test structs to per-point CSVs. Tests that need these files are skipped
automatically when they are not present.

Measurement conventions verified against the data (see the fetch script
docstring): `Vs` in the test structs is **per-phase rms** (power balance
`P = 3·Vs·Is·pf` closes with the circuit-model power factor at the 10 Hz
locked-rotor points to ~1%), and `Tshaft` is negative in the raw structs
(braking direction) — comparisons use magnitudes.
