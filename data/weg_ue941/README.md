# WEG UE 941/713 — frame-80 4-pole PMSM (high-power variant)

Higher-power companion to the UE 921 series in the same frame-80
housing. Different winding (higher kT, higher current capacity).

## Source

Nameplate and test bench documentation. kT = 1.86 Nm/A, peak torque
28.5 Nm (PRS 3x overload). No published electrical datasheet
(L_d, L_q, psi_f, R_s unknown from published sources).
