# Wang 54s/48p outer-rotor SPM — 13 kW in-wheel direct-drive

54-slot/48-pole fractional-slot concentrated-winding outrunner.
Prototype manufactured and tested with LCR-measured electrical
parameters — the only outrunner SPM in the validation set with both
full geometry and measured R_s, L_d, L_q.

## Source

Wang, Q., "Performance Evaluation of Outer Rotor Permanent Magnet
Direct Drive In-Wheel Motor Based on Air-Gap Field Modulation Effect,"
World Electric Vehicle Journal, 16(5):247, April 2025.
DOI: [10.3390/wevj16050247](https://doi.org/10.3390/wevj16050247)
