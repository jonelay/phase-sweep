# 14 mm Outrunner (Steel) — measured data

Lab-measured reference data for the steel-rotor variant of the 14 mm
outrunner (12-pole/9-slot SPMSM). Bench twin of an aluminum-rotor build.

## Source

Caliper/micrometer/gauge-pin geometry measurements and 3-channel
externally-driven open-phase back-EMF speed sweep. LCR 1 kHz winding
measurements (2026-03-16). All measurements by the project author.

## Files

| File | Content |
|---|---|
| `backemf_speed_sweep.json` | Distilled per-speed back-EMF results (raw record, not the measured import format) |
| `backemf_measured.json` | Back-EMF fundamental at W_REF in the measured import format, distilled from the sweep |
| `k_end.record.json` | End-effect correction record |
| `captures/` | Raw oscilloscope CSVs (3-channel phase voltages) |
