# Deylami Outer-Rotor BLDC

450 W automotive radiator cooling fan, 8-pole, 12-slot, concentrated
winding, ferrite magnets. Validation data from published FEM results.

## Source

Deylami et al., TechRxiv preprint, 2024.
DOI: [10.36227/techrxiv.171439839.97768997/v1](https://doi.org/10.36227/techrxiv.171439839.97768997/v1)

## Files

| File | Content |
|------|---------|
| `fem_flux_published.json` | Published FEM flux density data |

## Notes

- Motor definition is in `motors/deylami_fan.toml`; this directory
  holds validation reference data only.
