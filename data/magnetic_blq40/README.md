# Magnetic BLQ-40 IPM

6-pole interior-PM servomotor with SmCo magnets (Hitachi H-18B).
A peer-reviewed characterization of a commercial industrial servo —
publishes the nominal constant-parameter model but no geometry, winding,
or thermal data.

## Source

Caruso, Di Tommaso, Miceli, Nevoloso, Spataro, Viola,
"Characterization of interior permanent magnet synchronous motors for
loss model algorithm identification," 21st IMEKO TC4 Int. Symposium,
Budapest, Sept 2016, pp. 37–41, Table 1.
